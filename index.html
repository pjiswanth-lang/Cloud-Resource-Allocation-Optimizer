PROJECT METHODOLOGY

Mathematics behind the optimizer

This prototype connects the required graph theory and combinatorics concepts to a practical cloud scheduling simulation.

⌘

Directed Acyclic Graph

Tasks are nodes and dependencies are directed edges. Cycles are rejected because they prevent a valid task order.

GRAPH THEORY
⇢

Topological sorting

Determines an order in which every prerequisite appears before the task that depends on it.

DEPENDENCY MODELLING
◇

Greedy selection

Chooses a ready task using a documented heuristic, then assigns it to a compatible virtual machine.

COMBINATORIAL HEURISTIC
▥

Performance metrics

Uses makespan, estimated CPU utilization, throughput and critical path duration to evaluate results.

OPTIMIZATION EVALUATION
ⓘ

Project scope: This is a browser-based simulation, not a connection to real AWS, Azure or Google Cloud infrastructure. Metrics are estimates based on the workload model and should be interpreted accordingly.
